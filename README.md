# T-Rex DQN

Double DQN-агент для игры [Chrome T-Rex Runner](https://wayou.github.io/t-rex-runner/).
Агент не делает скриншоты: он читает состояние игры через JavaScript в
Playwright, выбирает действие и тоже управляет игрой прямыми вызовами JS.
Проект вырос из Q-learning презентации: вместо таблицы `3 состояния × 2 действия`
теперь нейросеть, replay buffer, target network и три действия.

Поддерживаются **Windows 10/11, macOS и Linux (x86_64)**. Нужен Python **3.12**
(зафиксирован в `.python-version`) и менеджер пакетов [uv](https://docs.astral.sh/uv/).

---

## Установка

Команды ниже выполняются **из папки проекта**. Перейди в неё:

```powershell
# Windows (PowerShell)
cd C:\path\to\trex
```

```bash
# macOS / Linux
cd /path/to/trex
```

### Шаг 1. Установить uv

| ОС | Команда |
|---|---|
| Windows (PowerShell) | `winget install --id=astral-sh.uv -e` |
| Windows (альтернатива) | `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 \| iex"` |
| macOS (Homebrew) | `brew install uv` |
| macOS / Linux (универсально) | `curl -LsSf https://astral.sh/uv/install.sh \| sh` |

После установки перезапусти терминал, чтобы `uv` появился в `PATH`.
Python 3.12 uv скачает сам; при желании его можно установить заранее:

```bash
uv python install 3.12
```

### Шаг 2. Зависимости и браузер

Команды одинаковы на всех ОС:

```bash
uv sync                         # создать .venv и поставить numpy, torch (CPU), playwright
uv run playwright install chrome  # установить Chrome для Playwright
```

На Debian/Ubuntu, если Chrome не запускается из-за недостающих системных библиотек:

```bash
sudo uv run playwright install-deps chrome
```

Если хочешь использовать Chromium вместо Chrome, установи
`BROWSER_CHANNEL = None` в `trex.py` (строка 17) и выполни:

```bash
uv run playwright install chromium
```

## Запуск

Одни и те же команды работают в PowerShell, bash и zsh:

```bash
uv run trex.py          # по умолчанию: финальный забег (PLAY_BEST = True)
uv run trex.py --play   # то же самое, явно
uv run trex.py --train  # обучение: 4 окна, headless
```

Флаги обрабатываются напрямую через `sys.argv` (без `argparse`), поэтому
порядок не важен. Эквивалентный вариант с явным Python:

```bash
uv run python trex.py --train
```

**Важно для финального режима:** окно Chrome должно быть видимым. Если его
свернуть, игра ставится на паузу и эпизод отбрасывается. В обучении окна
headless, поэтому это не мешает.

### Что делает каждый режим

| | `--play` / по умолчанию | `--train` |
|---|---|---|
| Веса | `best_dqn.pt` (если есть), иначе `dqn.pt` | `best_dqn.pt` имеет приоритет над `dqn.pt` |
| Окон Chrome | 1 | 4 |
| Окно | видимое | headless |
| Эпизодов | 5 (`FINAL_ATTEMPTS`) | 1000 |
| Общий лимит времени | нет | 120 минут |
| Лимит одного эпизода | нет | 300 секунд |
| Исследование (epsilon) | 0 | 0.30 → 0.01 (после загрузки `best_dqn.pt`: 0.10 → 0.01) за 500 000 решений |
| Обучение сети | выключено | включено |
| Скорость игры | `MAX_SPEED = 13.0` | `MAX_SPEED = 13.0` |
| Сохранение | `best_dqn.pt`, если побит рекорд | `dqn.pt` каждые 20 эпизодов и в конце; `best_dqn.pt` при рекорде |
| Проверка рекорда | — | раз в 100 эпизодов, забег до 120 с, без исследования |

Константы режима находятся в начале `trex.py`. В частности, `TRAIN_GREEDY`
позволяет учиться без случайных действий; `STEP_DELAY = 0.02` задаёт tempo —
около 50 решений в секунду.

### Остановка

`Ctrl+C` останавливает все окна. В режиме обучения последние веса
сохраняются в `dqn.pt`, лучшие в `best_dqn.pt` не перезаписываются.

## Как устроен проект

### Поток данных

```text
Chrome / T-Rex Runner
        │  STATE_JS: x, speed, dist, passed, obstacles, jumping, ducking...
        ▼
   encode() ──► вектор из 12 признаков
        │
        ├─► Agent.act()      жадное действие по Q-сети или случайное (epsilon)
        ├─► jump_allowed()   запрет прыжка, если препятствие не перепрыгивается
        └─► forced_action()  жёсткие правила по типу препятствия
        ▼
   CONTROL_JS: run / jump / duck
        │
        ▼
   награда → replay buffer → learn() (Double DQN) → новые веса
```

### Состояние (12 признаков)

`encode()` (`trex.py`) превращает данные из игры в `float32`-вектор:

- 6 чисел — one-hot класс ближайшего препятствия: нет препятствия, малый
  кактус, большой кактус, низкий птеродактиль, средний птеродактиль,
  высокий птеродактиль;
- `dt / 60` — время до препятствия в кадрах (расстояние до носа динозавра /
  текущая скорость);
- `width / 20` — ширина препятствия в кадрах;
- `speed / 13` — текущая скорость;
- `gap / 60` — зазор до второго препятствия;
- флаг `ducking`, флаг `jumping`.

Из игры берутся только два ближайших препятствия. Высота птеродактиля
определяет класс: `y <= 60` — высокий (пролетает над головой), `<= 92` —
средний, ниже — низкий.

### Действия

| Код | Действие |
|---|---|
| 0 | `run` — бег (отпустить присед) |
| 1 | `jump` — прыжок |
| 2 | `duck` — присед |

Прыжок разрешён только за 6–24 кадра до препятствия, которое действительно
перепрыгивается. Поверх сети работают правила `forced_action()`, которые
не зависят от обучения:

- кактусы — прыжок с учётом кластера: апекс прыжка должен накрыть и следующее
  близкое препятствие;
- птеродактиль низкий или средний — прыжок;
- птеродактиль высокий — бег.

### Обучение

- `QNet`: `12 → 128 → 128 → 3`, ReLU на скрытых слоях, выход без активации —
  оценки Q(s, a) для трёх действий.
- **Double DQN**: следующее действие выбирает online-сеть, оценивает его
  target-сеть. Это уменьшает переоценку Q-значений.
- Replay buffer на 100 000 переходов; обучение начинается после 1000
  переходов и идёт раз в 4 решения батчем 64.
- Huber loss (`smooth_l1_loss`), градиенты ограничиваются нормой 10,
  оптимизатор Adam с `LR = 1e-3`, дисконт `GAMMA = 0.99`.
- Target-сеть синхронизируется с online каждые 1000 шагов обучения.
- Награды: `+0.01` за единицу дистанции, `+1.0` за пройденное препятствие,
  `-10.0` за падение. Награда за полёт копится с дисконтом и приписывается
  состоянию, из которого был начат прыжок, а не моменту приземления.
- Epsilon линейно снижается от стартового значения до `0.01`; в финальном
  режиме он всегда `0`.

### Окна и потоки

`window_worker()` поднимает отдельный Chrome через отдельный Playwright в
своём потоке. Все окна делят один `Agent` (сеть и буфер), доступ защищён
`threading.Lock`. На эпизод создаётся замороженная копия весов
(`clone_for_behavior()`), чтобы действия были стабильными, пока online-сеть
продолжает учиться. `clone_for_eval()` используется для проверки рекорда без
исследования и без обучения.

Счётчик эпизодов и запись в `results.csv` тоже защищены блокировками.
Устройство выбирается автоматически: CUDA, если доступна, иначе CPU;
`torch.set_num_threads(2)` ограничивает потоки, чтобы 4 окна не забирали все ядра.

### Особенности работы со страницей

- `STATE_JS` и `CONTROL_JS` читают/меняют `window.Runner.instance_` напрямую.
- `NO_PAUSE_JS` до загрузки игры отключает подписки на `blur`, `focus` и
  `visibilitychange`, иначе игра ставится на паузу при потере фокуса.
- `RESTART_JS` останавливает и заново запускает забег, возвращает контейнеру
  нормальный размер и включает arcade-режим (`startGame()`).
- `Runner.config.MAX_SPEED` переопределяется через JS до старта эпизодов.

## Возможные проблемы

**`Failed to download torch==2.15.0+cpu ... download-r2.pytorch.org ...
operation timed out`.** Некоторые версии `uv.lock` ссылаются на хост
`download-r2.pytorch.org`, до которого не всегда можно достучаться. В текущем
локе URL заменены на рабочий `download.pytorch.org` (SHA256 колес совпадает).
Если после `uv lock` ссылки вернутся, замени их обратно и повтори `uv sync`:

```powershell
# Windows (PowerShell)
(Get-Content uv.lock -Raw) -replace 'download-r2\.pytorch\.org','download.pytorch.org' | Set-Content uv.lock
uv sync
```

```bash
# macOS / Linux
sed -i.bak 's#download-r2\.pytorch\.org#download.pytorch.org#g' uv.lock
uv sync
```

**Браузер не найден.** Выполни `uv run playwright install chrome` или переключи
`BROWSER_CHANNEL` на `None` и установи Chromium. На Linux могут понадобиться
системные библиотеки: `sudo uv run playwright install-deps chrome`.

**Финальный забег не стартует / эпизоды отбрасываются.** Окно Chrome должно
быть развёрнутым и видимым — см. проверку `document.visibilityState`.

**Путь к проекту с кириллицей.** Работает нормально; в PowerShell бери путь
в кавычки: `cd "C:\path\with spaces\trex"`.
