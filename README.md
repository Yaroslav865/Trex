# T-Rex DQN

Double DQN для Chrome T-Rex Runner. Проект вырос из Q-learning презентации:
вместо таблицы `3 состояния × 2 действия` теперь нейросеть, replay buffer,
target network и три действия.

## Что изменилось после Q-learning

| Было в презентации | Стало в DQN |
|---|---|
| 3 состояния: далеко / средне / близко | 12 признаков: класс препятствия, время до него, скорость, ширина, зазор до второго, присед, прыжок |
| 2 действия: прыгать / не прыгать | 3 действия: `run`, `jump`, `duck` |
| `q_table.npy`, 3×2 | `QNet` 12 → 128 → 128 → 3, `best_dqn.pt` |
| обновление Q-таблицы | Double DQN + replay buffer + target network + Huber loss |
| `EPSILON = 0.1` постоянно | `epsilon` 0.30 → 0.01 (после загрузки best — 0.10 → 0.01) |
| `GAMMA = 0.9` | `GAMMA = 0.99` |
| 150 эпизодов, 1500 шагов | 1000 эпизодов, без лимита шагов |
| `STEP_DELAY = 0.05` | `STEP_DELAY = 0.02` |
| награда +1 / −100 | дистанция 0.01, препятствие +1.0, падение −10.0 |
| одно окно | 4 окна обучения, общий опыт |
| нет финального режима | финал без исследования, 5 попыток, `best_dqn.pt` |
| птеродактиль не различается | правило высоты: низкий и средний — прыжок, высокий — бег |

## Установка

Нужны Python 3.12, [uv](https://docs.astral.sh/uv/) и Chrome/Chromium.

```powershell
uv sync
uv run playwright install chrome
```

Если используется Chromium: `BROWSER_CHANNEL = None` и
`uv run playwright install chromium`.

## Запуск

```powershell
uv run trex.py          # финальный забег, 5 попыток, окно видно
uv run trex.py --train  # обучение, 4 окна, headless
uv run trex.py --play   # принудительно финальный забег
```

## Параметры

- `GAMMA = 0.99` — долгий горизонт;
- `LR = 1e-3` — Adam;
- `BATCH = 64`, `BUFFER_SIZE = 100_000`, `TARGET_SYNC = 1000`;
- `EPS_START = 0.30`, `RESUME_EPS_START = 0.10`, `EPS_END = 0.01`,
  `EPS_DECAY_DECISIONS = 500_000`;
- `EPISODES = 1000`, `TIME_LIMIT_MINUTES = 180`, `WINDOWS = 4`;
- `MAX_STEPS = 0` — эпизод до падения;
- `FINAL_ATTEMPTS = 5` — финал делает несколько попыток и сохраняет лучшую.

Обучение и финал идут на `MAX_SPEED=13.0`: птеродактили низкий и средний
перепрыгиваются, высокий безопасен для бега, кактусы в кластере прыгаются
с учётом второго препятствия. Управление — прямые вызовы игры через JS.

## Результаты

Текущий `best_dqn.pt` (обучен на `MAX_SPEED=13.0`, с птеродактилями и ускорением):

```text
distance: 443 549
score:    11 088
decisions: 780 482
learn:     325 346
```

Пять финальных забегов по 10 минут каждый завершились только по лимиту
времени: 443 540 / 443 269 / 443 530 / 443 549 / 442 030 — ни одного падения.

Старый low-speed чекпоинт сохранён в `best_dqn_low.pt` (175 092 / 4 377 очков
на скорости 6.5) и в репозиторий не входит.

Финальный режим загружает `best_dqn.pt`, отключает исследование и делает
`FINAL_ATTEMPTS` попыток на `MAX_SPEED=13.0`. Результаты пишутся в
`results.csv`; если попытка прошла дальше рекорда, обновляется `best_dqn.pt`.

## Файлы

- `trex.py` — сеть, обучение, финальный забег.
- `best_dqn.pt` — лучшие веса.
- `dqn.pt` — последние веса обучения (в git не входит).
- `results.csv` — журнал эпизодов и финальных попыток.

## Остановка

`Ctrl+C`; в обучении последние веса сохраняются, `best_dqn.pt` остаётся
лучшим.
